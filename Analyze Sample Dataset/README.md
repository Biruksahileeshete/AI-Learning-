📖 What This Code Does
A simple data analysis tool that loads student data and performs analysis using Pandas, NumPy, and Matplotlib. It shows statistics, creates visualizations, and generates reports.

✨ Features
Create sample student dataset

Load/Save data from CSV files

View dataset information

Calculate statistics (mean, median, mode, std dev)

Check for missing data

Analyze grades by subject

Find correlations between variables

Identify top performing students

Create 8 data visualizations

Generate complete report

📊 Visualizations Included
Bar Chart - Average grades by subject

Histogram - Grade distribution

Scatter Plot - Study hours vs grades

Scatter Plot - Attendance vs grades

Box Plot - Subject grade distribution

Pie Chart - Grade category percentages

Heatmap - Correlations between variables

Bar Chart - Student age distribution

🛠️ Technologies Used
Python 3.x

Pandas - Data manipulation

NumPy - Numerical operations

Matplotlib - Data visualization
