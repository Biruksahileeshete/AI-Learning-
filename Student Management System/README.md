📚 Simple Student Management System
A beginner-friendly Student Management System built with Python using only basic concepts: variables, functions, loops, and Object-Oriented Programming (OOP).

🎯 Project Overview
This is a simple, no-fuss Student Management System that helps you manage students, courses, grades, and enrollments. It's perfect for beginners learning Python or anyone needing a basic school management tool.

✨ Features
✅ Add new students

✅ Add new courses

✅ Enroll students in courses

✅ Add and track grades

✅ Calculate average grades

✅ View all students and courses

✅ Generate student reports

✅ Simple menu-based interface

🛠️ Technologies Used
Python 3.x - Core programming language

No external libraries! - Pure Python only

No databases needed! - Everything runs in memory
