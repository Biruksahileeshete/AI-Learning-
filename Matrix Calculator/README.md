🔢 Matrix Calculator - NumPy Array Operations
📖 What This Code Does
A Matrix Calculator that performs mathematical operations on matrices using Python and NumPy. You input two matrices, and the program lets you perform various operations like addition, multiplication, transposition, and more through an interactive menu.

✨ Features
Add Matrices - Adds two matrices (same dimensions required)

Subtract Matrices - Subtracts matrix B from A (same dimensions required)

Multiply Matrices - Performs matrix multiplication (columns of A must equal rows of B)

Scalar Multiplication - Multiplies a matrix by a number

Transpose Matrix - Flips matrix rows and columns

Determinant - Calculates determinant (square matrices only)

Inverse Matrix - Finds inverse (square matrices with determinant ≠ 0)

Element-wise Multiplication - Multiplies corresponding elements (same dimensions required)

Matrix Statistics - Shows mean, std, min, max, sum, shape

Create Matrix - Create/replace matrices with user input

Display Matrix - View matrices in formatted table

Exit - Quit the program
